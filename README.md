# Telemann Corpus
A repository for encodings of music by German Baroque composer [Georg Philipp
Telemann](https://en.wikipedia.org/wiki/Georg_Philipp_Telemann) (1681-1767).

Encodings are in the [Humdrum representation](https://www.humdrum.org/).

The initial repository contains the works included in the corpus described in
Bell (under review), but other encodings in Humdrum are welcome.

See Bell (under review) for details concerning the encoding process and issues.

# Current Contents
The Telemann Corpus repository contains the following works (last updated 9 sep
2026).

## Solo instrument
- 12 Fantasias for Flute,  TWV 40: 2-13
- 12 Fantasias for Violin, TWV 40:14-25
- 12 Fantasias for Viol,   TWV 40:26-37

## Solo instrument with basso continuo
- Essercizii musici,
        TWV 41:F4, D9, a6, d4, B6, A6, G9, e5, C5, e6
- Sonate metodiche,
        TWV 41:g3, A3, e2, D3, a2, G4, h3, c3, E5, B5, d2, C3
